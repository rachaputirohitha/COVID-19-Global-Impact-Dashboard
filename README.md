# COVID-19-Global-Impact-Dashboard

## Project Overview
This project analyzes global COVID-19 data using Microsoft Power BI. The interactive dashboard presents case trends, death statistics, vaccination indicators, and country-level comparisons.

## Objectives
- Analyze COVID-19 cases and deaths over time.
- Compare COVID-19 statistics across countries.
- Explore vaccination indicators.
- Present key performance indicators through an interactive dashboard.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)

## Dashboard Features
- Total Cases and Total Deaths KPI cards
- Case Fatality measure and Average Daily Cases
- COVID-19 cases and deaths trend charts
- Country-wise comparisons
- Vaccination analysis
- Interactive country and date slicers

## Key Insights
- Trend charts help explore changes in reported cases and deaths over time.
- Country comparisons show differences in reported COVID-19 totals.
- Vaccination indicators provide additional context for comparing countries.
- Cases per million supports comparisons that account for population differences.

## Conclusion
This project demonstrates data preparation, analytical reporting, and interactive dashboard development using Power BI.
